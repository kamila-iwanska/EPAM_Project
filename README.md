
## Description
**This project was developed as part of Front-End Development Program led by EPAM Systems Poland for educational and training purposes.**

This project uses **Sass (SCSS)** for styling and compiles all `.scss` files into `.css` files stored in the `dist` folder. The setup is designed to be simple and efficient, requiring only two commands to get started.

Author: Kamila Iwańska

---

## Getting Started

### Prerequisites
Make sure you have the following installed:

- Node.js (recommended: latest LTS)
- npm (comes with Node.js)

---

## Installation

Install all dependencies:

```bash
npm install
```

### Development
To start the project (compile SCSS and watch for changes):
```bash
npm run dev
```
